# Descomposición de Polinomios (Ruffini Interactivo)

Aplicativo web interactivo para practicar la descomposición factorial de polinomios cúbicos mediante la **Regla de Ruffini extendida (1 o 2 veces)**, incluyendo soporte completo para raíces racionales ($\frac{p}{q}$).

## Características
- **Práctica Interactiva (20 Polinomios + Ejemplo Base):** Tabla de Ruffini paso a paso con verificación automática de fracciones, enteros y decimales.
- **Extensión Flexible (1, 2 o 3 veces):** Permite detenerse en el cociente cuadrático o extender la tabla por segunda vez hasta obtener $(x - r_1)(x - r_2)(ax + b)$ y su forma equivalente con coeficientes enteros.
- **Desarrollo Paso a Paso:** Explicación animada del ejercicio base $2x^3 - 3x^2 - 14x + 15$.
- **Solucionador Libre:** Permite ingresar cualquier polinomio cúbico $Ax^3 + Bx^2 + Cx + D$ y ver su tabla de Ruffini extendida.
